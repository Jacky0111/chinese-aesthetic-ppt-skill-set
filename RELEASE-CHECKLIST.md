# Release checklist

- [ ] Record generation method, provenance, and rights status for new assets; do not publish uncleared assets.
- [ ] Check facts, source credits, and text inside each image; list open items in `KNOWN-ISSUES.md`.
- [ ] Validate matching Skill IDs, versions, classifications, structure, and assets (including `--release`).
- [ ] Clone each repository into a clean folder and verify its README, installer, and relative image paths.
- [ ] Verify the links between the Chinese and English repositories.
