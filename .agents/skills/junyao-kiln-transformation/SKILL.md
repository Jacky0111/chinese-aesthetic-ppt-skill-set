# Jun Ware Kiln Transformation

Choose page structures based on the brief, then use Jun ware’s color relationships and flowing material quality to maintain a coherent style. Read `assets/README.md` first and consult relevant examples as needed. Historical evidence and modern interpretation are separated in `references/sources.md`.

## Visual language

- **Color:** Sky blue or blue-celadon establishes the base; purple-red, rose purple, and deep violet form irregular blooms and focal points. Milky white and gray-blue can soften transitions. Avoid fluorescent saturation and uniform three-stop gradients.
- **Material:** Suggest opalescent, opaque glaze with soft gloss and mingling color layers. Use natural flow, uneven boundaries, and localized color blooms. Avoid watercolor, smoke, or regular crackle overlays.
- **Layout:** Select columns, timelines, annotation studies, covers, or infographics according to the content. Let each page’s color flow support reading; do not repeat one fixed gradient ribbon.
- **Type and components:** Song-inspired display type can set the tone, with clear contemporary type for body copy. Use deep violet, blue-black, or contrasting pale text. Charts and information components can carry localized color flow while preserving data accuracy and readability.
- **Objects:** Express the style abstractly by default. Do not generate ceramic objects unless the content calls for them.

## Resource use

All resource paths are relative to this skill folder. Read `assets/README.md`, then select relevant images from `assets/examples/`. Extract the relationship among sky blue, purple-red, and deep violet, plus the opalescent gloss and flow. Do not copy the example’s text, composition, gradient path, or decorative placement. Recompose every page around the actual brief.
