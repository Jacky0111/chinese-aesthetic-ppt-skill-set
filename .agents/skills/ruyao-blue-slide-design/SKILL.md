# Ruyao Sky Blue

Design each page around its content, then apply Ruyao’s visual language consistently. Read `assets/README.md`; consult the primary reference and select relevant examples as needed. Use `references/sources.md` for historical context. Treat imagery as visual evidence, never as a page template.

## Visual language

- **Color:** Warm porcelain white, pale Ruyao celadon, mist blue, ink blue, and restrained cobalt. Sample values are hints, not mandatory fills; allow natural tonal variation.
- **Material:** Suggest translucent luminous glaze, delicate fine crackle, flowing glaze transitions, and soft highlights. Keep intricate texture away from small text and preserve readability.
- **Composition:** Choose aspect ratio, layout, hierarchy, and components from the brief. Do not make a pale centered field, a single focal point, or any example composition mandatory.
- **Typography and components:** Use legible Song-inspired display type with clear contemporary Chinese body text. Design charts, cards, timelines, and illustrations around their content and data.
- **Objects:** Express the ceramic feel abstractly by default. Do not generate a vessel unless the content calls for one.

## Resource use

Paths are relative to this skill directory. Read the asset index, then consult the primary image and only the examples relevant to the task. Extract color, glaze, crackle, light, and visual rhythm. Do not copy calligraphy, page copy, full composition, or element placement. Recompose each page around the actual input.
