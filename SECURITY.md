# Security policy

## Scope

Only the latest version is maintained. This covers the installer, packaging and validation scripts, CI configuration, and skill instructions that could cause unauthorized actions, data exposure, or prompt injection.

## Reporting

Prefer private vulnerability reporting on the repository's **Security** page, if enabled. Otherwise open an issue that only says you need to discuss a security problem privately; do not include exploit details, secrets, or personal data.

The maintainer will respond on a best-effort basis; no response time is guaranteed.

## When installing

Read a third-party skill's `SKILL.md` and scripts before installing it.
